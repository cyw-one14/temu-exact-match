本机识别服务

正在检查…

图搜入口、页面结果同步与关键词收集无需本机模型。图片自动核对需要本机服务；默认本地模型无需 API Key。

自动核对范围

每批数量只控制核对节奏，已采集候选自动进入后续批次。每张参考图最多采集100条去重候选，翻页、来源和检索词共用上限，满100条自动停止采集并核对；不足时按实际数量。页面停滞、需要登录或验证时暂停并保留数据。核对越多耗时越长，云端模式会增加模型调用。

使用步骤

  1. 加载扩展后，刷新 TEMU 页面并选择美国地区。
  2. 点击商品图片右上角“查同款”。
  3. 在图搜页面按需要登录、验证或启用原选品助手，选择美国站。
  4. 侧栏先核对主体，标题相似组可补充颜色；仍无法确认的商品再比较主体轮廓，两项轮廓指标均达90%按轮廓补充同款处理。结果区区分各类依据，原始标题和页面价格保留。可复制标题，按匹配程度、美元价格或销量排列。
