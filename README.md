# TEMU 完全同款助手

## 源码版本管理

本项目使用Git，默认分支main，远程使用GitHub私有仓库。0.2.1源码是首份版本基线；初始化之前的开发没有独立Git提交，不能把验证文档当作可自动回退的历史。

远程仓库：[cyw-one14/temu-exact-match](https://github.com/cyw-one14/temu-exact-match)（私有）。origin已配置，main跟踪origin/main；当前源码已上传。

Codex与Qoder的共同维护约定见AGENTS.md。开发前检查git status和相关diff，完成修改及验证后提交相关文件并使用git push上传。不要强制推送或覆盖另一位维护者的未提交修改。

仓库保存源码、安装说明、依赖锁文件和测试用例。node_modules、模型/.cache、ZIP/dist、运行日志、.local-*及密钥文件由.gitignore排除；换电脑后按开发环境步骤重新准备依赖和模型。扩展manifest的key是公钥，保留它以稳定插件ID。

可安装到 Chrome / Edge 的 Manifest V3 浏览器插件，侧栏优先比较同款真实价格与原始标题。使用商品主体分割、视觉特征和局部细节比对，支持 TEMU 图片右上角“查同款”、特卖数据图搜入口及正常页面数据同步。商品数据来自正常加载的 TEMU / 图搜页面，运行界面不含演示商品或模拟销量。

**当前是可加载的接入首版，第三方真实账号下的完整查询仍待验证。** 已根据公开前端代码适配 TEMU 商品卡片；不能把自动化测试通过当作真实图搜链路已经跑通。

## 在这台电脑上使用

运行依赖和本地模型已放在本项目目录，无需提供 API Key。

1. 双击本目录的 `启动服务.cmd`，等待本地设置页面显示“主体分割与特征比对已就绪”。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`，开启开发者模式。
3. 点“加载已解压的扩展程序”，选择 **D:\00 Work\temu-exact-match\extension** 文件夹。该文件夹内直接包含 `manifest.json`。
4. 固定“TEMU 完全同款助手”到工具栏。
5. 在 TEMU 前台选择美国地区，打开商品页或搜索结果页，等待图片加载。
6. **新流程**：刷新 TEMU 页面，点击商品图片右上角“查同款”。侧栏打开，并在新标签页启动特卖数据图搜，明确指定 Temu 平台。按网页要求完成登录、验证或启用原选品助手；确保 TEMU 正常浏览页面使用美国地区。
7. 侧栏每 2 秒读取图搜页正常展示的商品与销量，并按正常滚动 / 下一页 / 加载更多继续采集。没有商品条数或总时长截断，已读商品按来源与商品 ID 去重保留。可点“暂停采集，开始核对”提前核对，之后继续采集；页面结束、停滞、需要登录或验证时说明原因并暂停。自动主体匹配后展示原标题、页面价格和链接，再按同口径销量取 Top10，逐链接展示关键词原文。Top10 是展示数量，不是采集上限；搜索结果范围由网站决定，未核实全站覆盖。
8. 图搜结果同步后仅从已打开的选图页面读取原商品信息，分批比对已抓取图片和页面文字，更新同款、销量和关键词；核对过程不打开原商品或候选详情页；不需要点击人工确认。无法自动判断的商品显示原因并留在“自动处理 / 无法确认”区。需要重试时可点“重新自动核对”。该区默认折叠，且只列出图像证据较强、值得人工查看的最多 5 条候选，其余只计数不渲染；可点“展开全部”查看完整列表，导出 JSON 始终包含全部候选。

已有旧版扩展时，在扩展管理页点该插件的“重新加载”，然后刷新 TEMU 页面；确认扩展版本为 0.2.10。新按钮只有在刷新后的正常商品页 / 搜索页生效。设置可关闭图片按钮，或让点击只提取图片到侧栏。

0.2.10修复按钮点击无反馈的入口：点击立即显示“正在打开…”，按钮暂时禁用以避免重复查询；旧页面连接失效（包括同步抛错）提示刷新TEMU页面，8秒未响应会恢复按钮并提示。视口边缘按钮不再按图片内坐标静默拒绝；图片位置变化或已隐藏时提示更新按钮，仍只选择本商品可见图片。浏览器拒绝打开侧栏时会在普通标签页打开同一助手页面，先保存原选图，随后沿用原标题补读、图搜和连续采集流程；不新增权限或直接打开商品详情页。

仍可点工具栏插件图标上传本地图片并打开图片查询。本地文件没有公开图片地址，接第三方图搜时需在打开的图搜页正常上传同一张图，再点击侧栏的读取按钮；不需要 F12。手动搜索词单独放在折叠区，不属于推荐关键词。

0.2.9选图按钮排除隐藏/透明/被其他图片盖住的轮播图，点击时重新核对当前显示图片。商品ID优先绑定图片所属链接或公开商品图片声明；详情主图使用当前商品，避免取到附近推荐链接。原标题优先读取本商品公开声明、所属卡片标题或当前页面标题，空白/“商品图片”等通用描述不当商品名。打开图搜前还会从已打开的同ID商品信息补读标题，不新开详情页，也不先跑图片模型。

第三方Temu标签当前公开实现主要按原标题检索；没有标题时会从一次1688图片检索的首条结果取得标题。左上角正确的所选图片并不能证明下方候选都是视觉图搜结果。侧栏可展开“本次查询图片与原标题”查看实际输入，导出含imageSearchInput；缺标题会明确提示，插件不生成标题。专业版横幅的手套预览不属于普通可读取商品列表。诊断与限制见IMAGE-SEARCH-DIAGNOSIS.md。

安装包 `dist/temu-exact-match-extension.zip` 只包含扩展程序代码；解压后也可加载。图搜入口和页面同步无需本机模型，图片自动核对需要本机服务运行。要换电脑，请按后面的开发环境步骤安装服务依赖，首次使用会重新下载本地模型。

本地服务设置页：<http://127.0.0.1:43187/setup>。停止时双击 `停止服务.cmd`。本机服务只监听 127.0.0.1，不作为公网服务发布。

启动 / 停止入口直接使用 Node.js，兼容 Windows PowerShell 禁止执行 `.ps1` 文件的环境，无需更改系统执行策略。重复点击启动会复用已就绪的本项目服务；启动失败时窗口保留错误提示，日志位于 `.cache/service-error.log`。

本机服务启动后在后台保持运行，关闭侧栏或浏览器不会停止它，无需每次使用都重新启动。需要登录Windows后自动启动时，双击`开启开机自启.cmd`；当前用户Startup文件夹会加入本项目专用快捷方式，以隐藏窗口调用现有服务管理器，不自动弹出设置网页，不需要管理员权限。双击`关闭开机自启.cmd`只取消以后的登录自启，当前服务继续运行；立即停止仍用`停止服务.cmd`。服务仅监听本机43187端口，关机/注销后不能继续运行，睡眠期间暂停，下一次登录由启动项重新启动。启动记录见`.cache/autostart.log`；项目目录或Node.js安装路径改变后，应重新开启自启以更新快捷方式。此设置只在执行它的电脑/用户上生效，源码和扩展ZIP不会替其他电脑安装启动项。

维护命令为`node scripts/service-autostart.mjs enable|disable|status`。脚本只管理`TEMU Exact Match Service.lnk`并核对项目路径与归属，不覆盖同名但属于其他项目的启动项。采用[微软支持的当前用户Startup快捷方式](https://support.microsoft.com/en-gb/windows/experience/startup-boot/configure-startup-applications-in-windows)；不修改PowerShell执行策略。

## 同款判断规则

- **唯一标准是图片中的商品主体一致**：同图证据、SIFT 快速核验或主体模型确认一致后保留同款；只有图像证据显示商品主体不同才排除；初步不同的候选先复核镜像与旋转，仍无法对齐时保留无法确认。背景、排版、图片说明文字不属于商品主体。
- 当前0.2.9沿用0.2.6规则，先按标题相似/不相似分组，两组全部核对主体。主体一致即同款；仅标题相似组在主体核对完成且未匹配后，允许主体关注区域颜色相近按用户规则归为同款，并注明颜色补充依据。品牌不单独放行。
- 同一种商品的单件 / 多件装链接都参与主体同款比较，原始标题、价格和链接分别保留，售卖数量差异单独注明；SKU 未绑定时不自动换算单件价。
- 先对已抓取标题分组、排序，再走原页面同图路径。后续两组候选都运行SIFT、完整实例与原BiRefNet-lite + DINOv2，包括镜像/旋转及人体关注；完成后仅标题相似组可检查主体颜色。标题不相似或缺失均不跳过主体核对，不生成商品价格、原标题或推荐关键词。
- 图片主体明显不同的图像证据优先；照片模糊、遮挡、缺少关键细节等未确认情况保留待核对，不冒充已确认同款。云端也只采用有具体图像依据的主体检查结果，文字规格检查不能否决它。
- 原商品信息仅从已打开页面读取；原始图片和对应商品已有相册最多 3 张用于核对，不打开原商品或候选详情页。新选图会清空旧查询；旧判断会在匹配策略更新后重新自动核对。

## 价格与标题

- 同款卡片优先展示页面原始标题、价格、商品链接与采集来源 / 时间，支持复制完整标题；不让模型改写商品名称或生成价格。
- 读取可见当前价格时排除划线原价和优惠券金额；无法可靠读取时显示未知。价格区间、起价与预估 / 优惠价分别标注，具体 SKU / 优惠条件未绑定时不会宣称是结算价。
- 使用已抓取页面的原始标题和价格，保留来源 / 采集时间；核对时不补开详情页。兼容重复的货币符号（如 $ $1.68）、拆分的货币符号 / 整数 / 小数、纯数字价格容器与价格区间，并持续同步后加载的价格；价格更新独立于图片核对，主体核对期间也持续同步已有商品的价格，并允许点击读取按钮更新价格，不改变正在核对的图片或文字。缺少价格或规格时保留未知。按价格排序只处理已识别为 USD 的普通显示价 / 区间起价，不把其他币种、未知价格或条件价混入低价排名。
- 默认优先展示页面同图匹配，再展示后续主体核对结果；可切换页面 USD 价格 / 起价排序或按同口径销量排序。标题保留页面全文（上限 2,000 字符），外观层级及未核实规格随结果显示。

TEMU 图片地址可能以 `.jpg` 结尾，但通过 `format/avif` 返回 AVIF 内容。站内图片现在按实际内容解码，并自动转换为 PNG 后识别，支持 JPEG、PNG、WebP、AVIF 和 GIF 首帧。图片体积 / 像素限制仍保留；返回网页、文本或损坏内容的地址会明确提示重新选择产品图片。

## 销量与关键词

- 只读取商品页面明示的已售文字，不把评价数、评分、库存或“热卖”当作销量。
- `10K+ sold` 保留为下限；`4.2K sold` 保留为约数。未知销量不会伪造为 0。
- 只在已自动匹配结果中排序，来源中的“外观同款”层级明确保留；不同国家站或不同统计周期分别处理。统计周期未知会明确注明。
- “销量最高”只限已采集且工具自动确认同款的结果。默认每批核对 12 个商品，后续已读候选自动进入下一批；可设置每批 1–40 个。0.2.9移除页面120条和同步2分钟截断，先采集正常结果页，再运行主体核对；每批数和Top10不限制累计条数。手动检索最多选3组真实原词，每组均连续采集，已创建的结果页保留以支持继续。不把搜索页读完当作穷尽全站同类商品。
- 销量 Top10 先筛选主体一致或主体颜色补充同款中有销量的商品，再在同一国家、数据来源和统计周期内按页面显示数字取前 10 款。不足 10 款按实际数量展示；无关键词的商品仍保留名次，未知销量不入榜，明确 0 销量可参与排序。约数和销量下限保留原标识，无法证明精确名次；相同数字保持采集顺序。
- 优先收集商品行、商品卡片或对应商品结构化信息中明确标注的关键词，要求商品 ID 对应、词出现在原文证据内且有采集页面，保留原词、证据、来源链接与采集时间。未关联具体商品的图搜推荐词不进入推荐。没有有效关键词字段时，按标点摘录最多 3 段商品标题原词，不翻译、不组合、不让模型补词，侧栏标注“商品标题原词”。标题缺失或无法摘录时保留空结果。重复同步不累积重复词，也不保留本次页面已移除的旧词。
- Top10 逐链接显示原标题、页面价格、销量、同款依据和关键词；全部同款卡片另有“此链接关键词”，包含未进 Top10 和未知销量的链接，未知销量词仅作来源展示。关键词原文证据和采集页面可展开查看。
- 分析可导出 JSON，包含销量分组、每组入选前10款商品及salesRank / keywordEvidence、全部候选、每条同款链接的词证据、采集时间、判断依据与规格缺失项。新增collection / collections保留各次查询累计去重数量、结果页、采集状态与停止原因，siteWideComplete恒为false，不能以采集数量推算全站总量。汇总keywords保留兼容；手动检索记录单独导出。
- 第三方数据明确标为“来源：特卖数据图搜”；与 TEMU 页面已售数字分开排序。国家站无法从页面确认时显示“国家站尚未核实”。
- 第三方销量默认读取周期未知的“已售出”数字。设置可改为页面明确展示的日 / 周 / 月 / 累计销量；缺少所选周期时保持未知，不拿其他周期补齐。
- “月销量”和“近 30 天销量”、“周销量”和“近 7 天销量”分别保留，未确认定义一致时不放入同一排名。
- “畅销同款商品关键词”指销量领先商品的页面关键词或标题原词，不代表这些词自身的搜索量、销量贡献或转化率最高。未确认同款或没有页面销量时，不输出推荐词。

## 图片识别与数据流

默认使用 [BiRefNet-lite ONNX](https://huggingface.co/onnx-community/BiRefNet_lite-ONNX)（主体分割）及 [DINOv2-small ONNX](https://huggingface.co/Xenova/dinov2-small)（视觉特征），通过 Transformers.js 在本机 CPU 运行，新增模型约 250 MB，固定版本后缓存在 `.cache/models`。本机实测首次主体提取约 18 秒，新候选约 12–24 秒；重复图片复用缓存，主体特征保存在本机 .cache 中，服务重启后也可复用（按完整图片内容哈希匹配、复用期限 30 天、约 256 张）；模型或预处理版本变化需切换缓存版本。前期沿用原始商品图片地址进行图搜，读取正常页面候选；页面图片初筛只使用标准化像素及同一官方图片资源证据，不使用主体特征或其缓存。所有已读取候选完成页面图片匹配后，才用主体模型核对未确认候选。同图结果无需等待主体核对，默认优先展示。SmolVLM 仅保留为原有诊断接口，推荐词不使用其生成词。

本地模式下上传图片传给本机服务；TEMU 会接收到正常搜索关键词和商品页面请求。点击网页“查同款”并使用第三方图搜时，会把所选公开商品图片地址、商品 ID 和标题放入特卖数据图搜网址，后续查询由该网站正常执行。本地文件需由用户在第三方页面自行上传。首次下载模型需要连接 Hugging Face。云端模式则会把图片和待核对商品文字发给用户设置的视觉 API，需用户自己的密钥；密钥保存在 `.local-config.json`，不会包含在扩展安装包或分析导出中。

云端兼容接口参考：[OpenAI 图片输入说明](https://developers.openai.com/api/docs/guides/images-vision)、[阿里云视觉理解说明](https://help.aliyun.com/zh/model-studio/vision)。本地模式无需云端账号或付费 API。

## 当前验证范围与限制

已提供自动化检查：销量口径、同款严格门槛、规格子串误判、多 SKU 保守处理、页面 DOM 读取、CORS 来源限制、图片地址限制，以及本地模型实际推理测试。

**当前 TEMU 自动测试页面触发了安全验证，尚未在用户正常登录的真实 TEMU 浏览器页面完成端到端验证。** 插件不会绕过验证。请在自己的正常 TEMU 页面完成验证 / 登录后使用；页面布局变化可能需要更新读取器。

页面读取只处理正常展示的公开商品信息，不调用TEMU私有接口、不提取登录Cookie、不接入卖家后台或下单操作。TEMU search_result.html和第三方Temu图搜结果页可连续采集；插件先读取当前DOM再按视口逐段滚动，保留虚拟列表已移出的商品，识别本查询的正常下一页 / 加载更多。未识别的导航、网站未返回的商品、权限限制或其他检索词覆盖的商品不会凭空补入；“页面已显示结束”只指当前搜索结果。可继续不同真实原词查询扩大覆盖，仍没有全站完整目录的证明。侧栏关闭会暂停，重新打开后可继续；浏览器会话存储空间不足会明确提示数据仅在当前侧栏内，应保持打开并导出。

第三方接入使用正常图搜网页与 DOM 读取，没有调用原插件的通用请求桥，也没有复制其认证信息。公开图搜前端目前使用 `a.list-item`、`.title`、`.sold` 商品卡片，适配器同时支持有标题的销量 / 关键词表格。网站布局、权限或返回字段变化时可能需要更新适配器；没有商品结果时会保留明确的等待 / 验证提示。

## 快速特征核验

本机已准备独立 Python / OpenCV 环境，使用 MaaFramework 采用的经典特征匹配思路；没有引入它的界面控制或自动点击流程。试验选择 SIFT，AKAZE 在当前样本的严格覆盖条件下未产生可采用的快速匹配。

仅处理已抓取图片，不打开商品页。参考主体已缓存时，牙膏挤压器实际公开图片的核对接口约 0.9 秒，候选未进入主体模型；不代表所有候选或不同相机视角都能秒级完成。小图、背景复杂、缺少特征、遮挡、局部误差等情况回到原模型。样本覆盖手套与牙膏挤压器的压缩、二维旋转、换色、修改白色结构、共享包装、数量减少及空白图；不是全品类准确率验证。

换电脑需要 Python 3.10+，可运行：

```powershell
node scripts/prepare-features.mjs
```

依赖固定在 server/feature-requirements.txt，安装到本项目 .cache/feature-runtime，服务启动后复用常驻离线核验进程。缺少依赖时原主体模型仍可用。health.fastFeatures 显示核验状态。试验结果见 .cache/subject-validation/feature-trial.json 和 fast-api-report.json。

## 商品区域关注（0.2.1）

后续主体核对新增人体语义识别与每图颜色分布的联合关注：原图和原前景保留，仅降低两种证据共同支持的人体区域权重。木材、米色、手套等商品或颜色有歧义的部分继续参与核对。标题只可提供内部区域类别提示，不参与同款裁决，不会生成搜索关键词。

区域关注使用本机固定版本CLIPSeg模型和颜色聚类；首次未有模型缓存时会下载，已有本机模型。关注范围与特征持久缓存，翻转/旋转复用已识别权重，不重新跑人体识别或分割。若区域关注不可用，明确说明并保留原主体流程；已应用关注的候选必须通过商品区域的特征、几何和局部图像内容检查，细节核验缺少依赖/失败则保持无法确认。只有一块共享手部、戒指、商标或包装不能据此自动确认。

图搜入口、页面抓图和原价/原标题/链接采集仍按现有流程，不因该功能打开商品页。当前判断策略为title-groups-v15；health.productAttention表示区域模型状态。当前截图木梳在已降低部分手部影响后仍未满足商品细节对应，不能宣称已解决多件参考与单件候选/跨拍摄角度问题。记录见PRODUCT-ATTENTION-EXPERIMENT.md。

## 页面字段与未确认说明（0.2.2）

候选的品牌、型号、规格独立显示在“页面品牌与规格”区，与图像判定分开。明确的当前商品字段/结构化字段保留原文及来源；标题中明确出现的件数、材质词、颜色、尺寸单位/尺码按标题原文展示，并说明尚未绑定图片对应SKU。没有公开标注的品牌/型号显示“当前页面未展示”，不从店铺名、商品ID或图片推测。

图搜统计区分同款、未确认和明确不同；未知品牌/规格不属于图像失败依据。图像依据显示具体未通过的特征指标，以及完整前景比对可能受到多件拼图/摆放影响的说明，不把前景区域数量当商品件数。红框手套仍有未识别的情况，单件区域和方向试验尚未可靠通过，没有降低门槛强行接受；详情见GLOVE-MATCH-DIAGNOSIS.md。

## 标题优先与配色推定（0.2.4）

此节记录历史实现；0.2.6已用下述两组主体先行规则替代品牌/配色放行和跳过不相似标题的行为。

按用户最新要求，已抓取标题先归一化件数、颜色、营销用词及少量同义词，优先比较关键描述相近的候选。只有已知不同商品类型/相关性不足才暂缓慢速主体核对，保留同图快速路径且不判不同款；无标题或无法识别商品类型时保留原图像核对。此层是有限词表和原词规则，不是语言大模型或全品类语义识别。

标题关键描述高度重合，或明确品牌相同且商品类型及关键描述相符，可比较原分割前景64桶粗配色；达到0.85规则值时显示inferred-match/“标题 / 配色推定同款 · 细节未核验”。推定不能保证结构/纹理一致，前景也可能含手或其他物品，不将该分数叫同款概率。不满足时继续原完整主体核验。品牌未知、平台名、店名或同品牌不同类型不单独接受；数量差异仅附注，不改原价/原始标题/链接，不自动打开商品详情页。

推定商品进入同款价格与标题结果，卡片和计数明确区分；已核验同款的销量关键词推荐仍只使用图像已确认结果。不会把推定商品混入已核验商品的关键词。

用三个红框真实图片URL及截图可见标题做本机HTTP复测，粗配色约0.916/0.942/0.875，均进入推定层；缓存前景下约520/247/231ms，含候选图片下载，不含参考下载/首次分割。输入标题来自截图文字，不是0.2.4浏览器重新抓取验证，主体细节仍未证实。新图片首次前景提取仍可能需十几秒。

## 完整同图压缩副本（0.2.5）

前期同图检查新增独立的压缩/缩放副本验证，不只依赖相同地址或像素完全相等。全图分数非常接近时，再检查512px图片的全部局部区域差异、双向纹理与四个象限分布；通过后按同图匹配展示，不进入慢速主体模型。全局颜色相似、大片空白、简单渐变或共享局部不能据此通过；主体特征门槛及标题/配色推定层保持原规则。

用户紫色手套真实参考图和624px图搜图复测，完整图片指标0.9946；不提供地址一致证据也通过局部验证，HTTP页面阶段返回visual-match，subject=null。历史同地址记录曾落入推定层，而用户截图卡片显示未确认；页面已关闭且旧诊断不含商品ID/前期同图记录，无法精确还原旧卡片的输入与更新过程，不宣称已证实唯一历史根因。

本机诊断现在同时保留页面匹配与后续核对的阶段、商品ID及同图证据，不记录标题、账号内容或图片字节。仅当前正式端口43187写入近期诊断，测试服务不污染真实记录。策略更新后旧结果自动重核；价格、标题、链接继续使用页面原文，不打开商品详情页。

## 标题两组均核对主体（0.2.6，当前规则）

| 标题组 | 主体核对 | 后续规则 |
| --- | --- | --- |
| 相似 | 一致 | 同款 |
| 相似 | 未匹配 | 再比较主体关注区域颜色，达到相近规则时同款；否则保留未确认/实际差异 |
| 不相似 | 一致 | 同款 |
| 不相似或标题缺失 | 未匹配 | 不按颜色单独放行，保留实际图像核对结果 |

原标题使用有限原词归一化规则分组，当前相似规则考虑关键描述覆盖；件数、颜色营销词等不妨碍数量不同的主体核对。品牌仅作记录。分组只决定排序和能否使用颜色补充，不过滤掉不相似标题的商品。

颜色检查在同图/SIFT/完整实例/主体及方向/已抓取备用图片核对之后。复用当前分割和商品关注范围，明确人体区域降权，原图和前景不修改；无法可靠读取颜色时不放行。保持0.85颜色规则，指标不是同款概率。卡片rule-match标注“同款 · 标题相似 / 主体颜色相近”，保留主体未匹配或差异记录；不是宣称结构细节已一致。

主体一致和按颜色补充规则归为同款的结果均进入销量排序和真实商品关键词来源统计，关键词来源注明判定依据；旧inferred-match不绕过新规则。价格/原标题/链接、数量附注、不折算SKU单价及不打开商品详情页约束保持。
